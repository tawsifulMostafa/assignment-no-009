# StudyNook - Online Room Booking Platform

StudyNook is a modern Rooms Booking system that makes room Bookings system easy , AnyOne with a Room can add room if logged in and also anyone can book any kind of room by choosing easily.


## 🌐 Live Website

(https://github.com/tawsifulMostafa/assignment-no-009)

## 🚀 Features

- Secure authentication using Better Auth
- Email/Password and Google Sign-In
- Browse all available Rooms
- Search books by Room Name
- Filter books by amenities ()
- Featured Rooms section on the homepage
- Private AddRooms/myListings/myBookings page
- Update Room information by owners
- Responsive design for Mobile, Tablet, and Desktop
- Modern and clean UI with smooth animations

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/tawsifulMostafa/assignment-no-009
```

Go to the project folder

 

Install dependencies

```bash
npm install
```

Create a `.env.local` file and add your environment variables.

Run the development server

```bash
npm run dev
npm run start
npm run build
```

Open

```
https://assignment-no-0008.vercel.app
```

## 📁 Environment Variables

Create a `.env.local` file and add the required environment variables.

```env
BETTER_AUTH_SECRET=
BETTER_AUTH_URL=
BETTER_AUTH_URI_DB=

GOOGLE_CLIENT_ID=
GOOGLE_CLIENT_SECRET=
```
